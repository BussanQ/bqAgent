# bqAgent 功能演进记录

本文根据当前分支可达的 Git 历史与本地代码整理，记录 bqAgent 从最小 Go Agent 到多渠道、本地工作区智能体的功能演进。

## 说明

- 仓库当前没有版本 Tag，因此本文以提交日期为时间线，不将日期解释为正式发布版本。
- 时间范围为 2026-03-15 至 2026-08-25，并以当前本地代码作为校验基线。
- 时间线按功能首次落地日期从早到晚排列；后续行为变化标记为“演进”或“可靠性”。
- 纯合并、忽略规则、测试约束和不改变产品能力的构建脚本调整不单独列出。
- 提交标题与实际改动不一致时，以代码差异和当前实现为准。例如历史中标题为 “Add files via upload” 的提交只增加了架构 HTML 文档，真正的附件能力更早已经落地。

## 当前能力概览

当前代码保留的主要能力包括：

- 单次任务、规划执行、终端多轮对话、会话恢复、后台任务和常驻 HTTP Server。
- OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 三种模型协议。
- 内嵌 WebUI、QQ Bot Gateway、微信 iLink、ServerChan Bot 等交互渠道。
- 工作区文件与 Shell 工具、网页搜索与抓取、Skill、Memory、MCP 和独立子 Agent。
- 持久化 Session、上下文裁剪与摘要压缩、checkpoint 恢复、结构化 Trace、评估和反馈。
- WebUI 工作区浏览/切换、文件预览与附件、供应商配置、模型切换、历史会话和删除会话。
- 路径边界、原子写入、输出上限、进程组取消、重复调用保护和模型请求重试等可靠性机制。

## 2026 年 3 月：从最小 Agent 到可持久化、多渠道运行时

### 2026-03-15 — Go Agent CLI 起步

- **新增最小 Agent Loop**：通过 OpenAI 兼容接口请求模型，执行工具调用，并将工具结果继续送回模型，直到生成最终答复。
- **新增基础本地工具**：首批工具为 `execute_bash`、`read_file` 和 `write_file`。
- **新增命令行入口和测试骨架**：项目可以直接通过 `cmd/agent` 构建和运行。
- **项目定名**：实现从 nanoagent 更名为 bqagent，Go module 和文档同步更新。

### 2026-03-21 — 工作区、会话与交互模式

- **新增工作区感知**：从项目目录加载 Markdown 上下文和日记记忆，本地工具以工作区根目录为边界运行。
- **新增规划模式**：`--plan` 允许先生成步骤，再按计划执行任务。
- **新增持久化 Session**：支持 `--resume` 恢复会话，并通过 `--background` 启动后台任务。
- **新增终端多轮对话**：`--chat` 提供交互式 REPL、自动持久化、`/exit`/EOF 退出和 `--chat --resume`。
- **新增网页搜索**：`web_search` 首次接入 Tavily，通过 `SEARCH_API_KEY` 和 `SEARCH_BASE_URL` 配置。
- **新增 `.agent` 上下文与 Memory 工具**：启动时补齐默认 Agent Markdown 文件，并允许跨运行保存和读取记忆。

### 2026-03-22 — 流式输出与运行日志

- **新增会话输出日志**：对话内容写入 Session 的 `output.log`。
- **新增自动日记记忆**：Chat 每轮任务和结果自动追加到当天 Memory 文件。
- **新增终端流式模式**：`--stream` 在 Chat 中逐 token 输出，同时保留工具调用流程。

### 2026-03-23 — HTTP Server 与 ServerChan

- **新增常驻 Server 模式**：`--server` 暴露健康检查和基于 `session_id` 的对话 API。
- **新增 ServerChan 推送和 Bot Webhook**：外部请求可进入持久会话，Bot 的微信回复也沿同一会话返回。

### 2026-03-25 — 统一运行时与微信 iLink

- **演进为共享运行时**：CLI 和 Server 复用运行时、对话装配和工具执行路径，规划/工具失败恢复更清晰。
- **新增可插拔 Channel 抽象**：ServerChan 和后续渠道共用 Turn 处理流程。
- **新增微信 iLink 渠道**：接入 iLink 消息轮询，并提供 `--ilink-login`、`--ilink-status` 终端登录和状态命令。
- **新增渠道回复清理与鉴权检查**：过滤不适合发送给用户的思考标记，并强化 Server API Key 校验。

### 2026-03-26 — `.env` 与基础可观测性

- **新增工作区 `.env` 加载**：Shell 环境优先，工作区 `.env` 作为配置回退。
- **新增模型、工具和 Turn 耗时日志**：记录模型请求类型、流式状态、工具耗时、迭代次数和错误状态。

### 2026-03-27 至 2026-03-28 — 外部编码 Agent 与路由统一

- **新增外部 Agent Broker**：支持通过 ACP 或 CLI 调用 Claude、Codex、Cursor 等外部编码 Agent，并保存外部 Session 状态。
- **演进 Chat/Server 路由**：终端 Chat 与 HTTP Server 共享对话服务、外部 Agent 路由和本地工具集；Server 默认监听地址恢复为本机 `127.0.0.1:8080`。
- **兼容 MiniMax 工具消息**：修正工具调用消息格式，使 OpenAI 兼容但行为有差异的模型能够继续 Agent Loop。

### 2026-03-29 — Workspace Skill

- **新增可执行 Skill**：发现 `.agent/skills/*/SKILL.md`，支持自动选择和显式 `/skill` 路由。
- **新增 Skill 热加载**：每轮重建 System Prompt，运行中的 Chat/Server 无需重启即可发现新 Skill。

### 2026-03-31 — 网页抓取

- **新增 `web_fetch`**：Agent 可以读取指定网页内容，与 `web_search` 形成“搜索后抓取”的网页信息链路。

## 2026 年 4 月：长上下文与可恢复执行

### 2026-04-06 — 上下文管理和 checkpoint

- **新增请求级上下文预算**：在每次模型请求前裁剪旧消息和已完成的工具调用证据。
- **新增可选摘要压缩**：将较早对话压缩为摘要，同时保留最近轮次。
- **新增 checkpoint 恢复**：从“摘要 + 最近消息”恢复紧凑工作上下文，原始 Session 历史继续保留。

### 2026-04-07 — 取消与错误可见性

- **可靠性：工具执行响应 Turn 取消**，模型请求终止时本地工具不再脱离生命周期继续运行。
- **可靠性：Server 模型错误写入服务日志**，便于排查无响应和上游异常。

## 2026 年 5 月：搜索、Skill 与机器人渠道扩展

### 2026-05-16 至 2026-05-20 — 双搜索后端

- **新增 Firecrawl 搜索后端**：`web_search` 一度切换为 Firecrawl 默认实现，同时保留旧 `SEARCH_*` 配置。
- **演进为 Tavily/Firecrawl 双后端**：`SEARCH_*` 选择 Tavily，未配置时可回退 `FIRECRAWL_*`；当前代码沿用这一优先级。

### 2026-05-17 — Skill 安装与快捷路由

- **新增 `install_skill`**：可以从 URL 安装 Skill。
- **新增首词/别名路由**：消息以 Skill ID 或 alias 开头时，可直接选择相应 Skill。

### 2026-05-18 — 渠道进度反馈

- **新增模型进度消息**：Channel Runner 可以向用户报告模型分析和工具执行阶段。
- **iLink 保留最终回复语义**：为避免提前消耗一次性上下文令牌，iLink 不发送中间进度，只发送最终结果。

### 2026-05-19 — QQ Bot Gateway

- **新增 QQ 机器人渠道**：通过 Gateway WebSocket 收取 C2C/群聊事件，无需自行部署 Webhook。
- **新增 QQ 会话状态、去重和等待提示**：将 QQ 用户映射到持久 Session，并避免事件重复回复。

### 2026-05-28 — QQ 并发与 Linux 构建

- **演进 QQ 事件处理**：复杂 Turn 异步执行，避免单个长任务阻塞 Gateway 后续消息。
- **新增 Linux amd64 构建目标**：Makefile 提供静态 amd64 产物构建入口。

## 2026 年 6 月：WebUI、多模态、工具扩展与 MCP

### 2026-06-13 — Channel 生命周期和资源治理

- **可靠性：Channel 生命周期统一管理**，后台 goroutine 从根 Context 派生并在关闭时等待退出。
- **可靠性：会话锁自动清理**，避免长期运行时锁表持续增长。
- **可靠性：QQ 心跳失败触发重连，Turn 失败或超时会通知用户**。
- **新增分层超时配置**：区分整轮 Channel 超时与上游模型请求超时。

### 2026-06-15 — 内嵌 WebUI 与压缩续跑

- **新增 WebUI Channel**：`GET /` 提供内嵌单页应用，`POST /api/v1/webui/chat` 通过 SSE 流式返回 token。
- **新增无外部资源的单文件部署**：HTML/CSS/JS 使用 `go:embed` 打包进二进制。
- **新增 TokenSink**：模型 token 流与服务日志分离，支持浏览器实时显示。
- **新增 WebUI 明暗主题与 Markdown 阅读体验**：页面逐步形成独立聊天产品界面。
- **新增 `AGENT_MAX_ITERATIONS` 配置**：运行轮数上限可由环境变量控制。
- **演进为自动压缩续跑**：默认通过上下文预算和摘要持续执行，不再把较小轮数上限当作正常终止条件；统一使用 1000 轮作为失控保险。

### 2026-06-17 — 渠道图片输入

- **新增 iLink 图片理解**：下载微信 CDN 加密图片，完成 AES 解密，并以多模态消息送入模型。
- **新增 QQ 图片理解**：读取 QQ 消息附件和纯图片消息，下载后复用统一多模态管线。

### 2026-06-18 — Claude Code 风格工具与并行调用

- **新增 `edit_file`**：按唯一精确字符串执行局部替换。
- **新增 `grep` 与 `glob`**：在 Go 内实现工作区内容搜索和递归文件匹配。
- **新增 `todo_write`**：维护 Session 级任务清单，并将状态同步到进度输出。
- **增强 `read_file`**：支持 `offset`/`limit` 分段读取。
- **新增并行工具执行**：无依赖工具最多并行执行 8 个，规划和 Skill 等有顺序依赖的调用保持串行。
- **演进 Session 恢复**：找不到 Session 时可降级创建新会话，服务日志与用户会话输出分离。

### 2026-06-21 至 2026-06-23 — MCP Client

- **新增 Streamable HTTP MCP Client**：启动时读取 `.agent/mcp.json`，执行握手和 `tools/list` 自动发现。
- **新增 MCP 工具注入**：外部工具以 `mcp__<server>__<tool>` 命名，JSON Schema 原样暴露给模型。
- **新增 best-effort 启动策略**：MCP 服务缺失、禁用、配置错误或不可达时记录告警，不阻止 Agent 启动。
- **可靠性：补强工具名碰撞、SSE 错误透传和文本换行处理**。

### 2026-06-27 — Shell 进程树治理

- **可靠性：取消整个 Shell 进程组**，防止长驻孙进程继承管道后让 `execute_bash` 和当前 Turn 永久挂起。
- **可靠性：QQ 预期重连重置退避并降低日志噪音**。

## 2026 年 7 月：停止控制、评估体系、多供应商与安全边界

### 2026-07-01 至 2026-07-03 — 可停止 Turn 和循环保护

- **新增渠道 `/stop`**：按 peer/session 取消当前对话中的子进程组，并绕过被长 Turn 占用的会话锁。
- **演进 iLink 轮询**：长 Turn 不再阻塞 `/stop` 等后续消息，失败消息也会被正确消费。
- **新增环境修复命令 Guard**：安装/修复命令失败后阻止模型在同一会话中无休止重试，并保留 stdout/stderr 供降级判断。
- **新增重复工具调用保护**：识别无进展的相同调用，避免渠道被模型循环占满。
- **新增统一时间戳日志**：提升常驻 Server 的日志可读性。

### 2026-07-12 — 交互渠道阶段 checkpoint

- **新增阶段预算和 checkpoint**：QQ/iLink/WebUI 可以按迭代数或时间保存阶段摘要，长任务可在同一 Session 中继续。
- **演进 Session 工作集**：Channel 优先从有界 `working_messages.jsonl` 恢复，并优先保留 System Prompt、摘要和最新用户请求。
- **新增 SSE 结构化进度事件**：WebUI 可以显示迭代、工具活动和阶段 checkpoint。

### 2026-07-13 — RunTrace、评估、子 Agent 与结构化 Memory

- **新增结构化 RunTrace 基础设施**：记录模型/上下文版本、token、工具摘要、耗时、错误、artifact、verifier 和反馈。
- **新增评估 Harness**：`cmd/eval` 支持 smoke/all 套件、replay/live 模式和重复执行。
- **新增反馈入口**：通过 `/feedback` 或 HTTP API 对 Run 进行 up/down 评价。
- **新增独立子 Agent**：`/agent` 可在隔离 Git worktree 中异步运行 Claude、Codex、Cursor 或 OpenCode，并支持 list/wait/result/interrupt/resume/apply/cleanup。
- **新增结构化 Memory**：以 `entries.jsonl` 保存 revision、来源 Run、置信度、supersedes 和敏感确认，支持中英文检索及旧 Markdown Memory 迁移。

### 2026-07-14 至 2026-07-15 — 多模型协议与可观测运行时

- **新增 OpenAI Responses 协议**：支持 Responses API 的输入、流式事件和工具调用转换。
- **新增 Anthropic Messages 协议**：支持 Anthropic 消息、流式响应和工具格式转换。
- **新增 WebUI 停止按钮**：发送按钮在执行期间切换为 Stop，通过通用 `turn_id` 取消模型请求和工具执行。
- **新增有效模型身份**：实际 `api_type` 和 `model` 注入 System Prompt，并由不暴露密钥的 `/api/v1/status` 返回。
- **演进 RunTrace 为按需开启**：`RUN_TRACE_ENABLED` 默认关闭，开启后才持久化 Trace 并开放反馈链路。
- **新增紧凑 Session 模式**：`messages.jsonl` 可在每轮结束后收敛为有界快照，同时可选保留 append-only 审计历史。
- **新增日志尾部限制**：限制 `output.log` 增长，避免长期 Session 无限占用磁盘。
- **新增随机分析进度文案**：减少长请求期间的静默等待感。

### 2026-07-17 至 2026-07-18 — OpenCode 与 WebUI 视觉体系

- **新增 OpenCode ACP 自动检测**：外部 Agent 配置可以启动 `opencode acp`，并完善各 Agent 的 ACP/CLI 覆盖配置。
- **新增极客终端风格 WebUI**：重塑页面布局、色彩和状态表达。
- **新增科技蓝粒子背景**：WebUI 加入 Canvas 粒子动效。

### 2026-07-23 — Pi 风格 Agent Loop 演进

- **演进 Skill 为渐进式披露**：System Prompt 只索引 Skill 名称、描述和路径，模型需要时使用 `read_file` 读取完整 `SKILL.md`；`/skill` 回到同一主循环执行。
- **新增截断工具批次 Fail-Closed**：模型输出达到 token 上限且工具参数不完整时，不执行任何副作用工具，并引导模型重发完整调用。
- **新增结构化 Tool Event**：按序记录工具开始、结束、耗时、参数摘要和截断状态，供 WebUI 时间线消费。
- **增强多模态上下文预算**：估算图片 token，并在超预算时优先移除旧图片而保留文本提示。
- **增强工具错误恢复和可访问性**：工具错误返回模型继续处理，WebUI 状态区域增加辅助技术可访问属性。

### 2026-07-27 — 安全边界与原子持久化

- **新增统一 SafePath 边界**：文件、Skill、Workspace 和附件路径拒绝目录穿越及越界符号链接。
- **新增原子文件写入**：Session、Memory、状态文件等通过临时文件替换，降低中断导致文件损坏的风险。
- **新增工具输出上限**：`BASH_OUTPUT_MAX_BYTES` 和 `READ_FILE_MAX_BYTES` 控制返回模型的内容大小，并添加截断标记。
- **新增 MCP 环境变量白名单**：只有 `MCP_ALLOWED_ENV` 授权的变量可以用于 MCP Header，URL 禁止变量展开。
- **强化 Webhook、Gateway、外部 Agent 和子 Agent 生命周期**：补齐鉴权、关闭、进程回收和并发状态边界。

### 2026-07-30 — 附件、模型命令与生成指标

- **新增 WebUI 文件附件**：支持浏览器上传文件或引用服务端工作区文件；文本内容注入当前 Turn，二进制文件提供安全路径给工具读取。
- **新增附件安全限制**：限制单文件/总大小、文件数量、文本内联长度，并阻止工作区外路径和符号链接逃逸。
- **新增 `/model` 命令**：列出配置模型、切换当前 Session 模型和恢复默认模型，选择结果持久化到 Session。
- **新增生成指标**：采集首 token 延迟、输出 token、生成耗时和速度，并在服务/WebUI 中展示。

## 2026 年 8 月：WebUI 工作区、配置中心与模型可靠性

### 2026-08-06 — 工作区文件浏览和预览

- **新增 WebUI Workspace API**：分页列出目录和文件，并在页面侧栏中浏览工作区。
- **新增文件预览**：支持 UTF-8 文本、常见图片和二进制元信息预览。
- **新增浏览安全约束**：隐藏 `.git`，拒绝通过符号链接离开工作区；其他点文件仍可见，因此 WebUI 需要部署在可信边界内。

### 2026-08-08 至 2026-08-09 — 长任务控制与交互视觉

- **演进 WebUI 长任务策略**：默认取消固定阶段轮数、阶段时间和整轮超时，让同一请求持续运行到最终答复。
- **新增流式 idle watchdog**：流式请求由“无数据超时”约束，而不是固定总时长。
- **新增推理强度选择**：WebUI 提供自动/低/中/高档位，并分别映射到 OpenAI Chat、Responses 和 Anthropic 参数。
- **演进工作区侧栏布局**：桌面端移至右侧，并调整宽度和移动端抽屉行为。
- **新增粒子交互反馈**：粒子对指针和点击产生响应，并继续优化明暗主题变量。

### 2026-08-12 — 架构文档补充

### 2026-08-18 至 2026-08-19 — 后台 Server 与环境继承

- **补充 iLink 登录命令文档**：明确 `--ilink-login`、`--ilink-status` 的使用方式；能力本身已于 2026-03-25 落地。
- **演进微信压缩会话**：修复 iLink 在上下文压缩/阶段继续场景下不回复的问题。
- **新增 `.env` 子进程继承**：加载的 `.env` 值同步写入进程环境，使 Shell、MCP 和外部 Agent 子进程可继承配置。

### 2026-08-20 — 多工作区切换

- **新增 WebUI 工作区选择器**：浏览允许的服务端目录并将其直接作为工作区根目录。
- **新增 Workspace Registry**：每个工作区拥有独立 Service、Session 和工具边界，浏览器分别记住各工作区会话。
- **新增 `WEBUI_WORKSPACE_ROOTS`**：扩展 WebUI 可浏览/选择的服务端根目录集合。
- **演进浅色主题**：连续优化表面层级、对比度和可读性。

### 2026-08-21 — 全局 Agent 配置与惰性工作区

- **演进配置层级**：`~/.agent` 成为全局主配置目录，工作区 `.agent` 成为可选覆盖层；兼容旧 `workspace/` 布局。
- **新增按需创建工作区配置**：切换工作区不会自动写入 `.agent`，只有显式创建或写入 Memory 时才落盘。
- **演进 Session 存储位置**：Session 统一保存到全局 Agent 目录，并在元数据中记录所属工作区，避免项目目录污染。
- **演进附件入口布局**：附件按钮移至输入区左侧并统一视觉样式。

### 2026-08-22 — Provider 设置、历史会话和跨层 Skill

- **新增 WebUI Provider 设置中心**：管理 Provider、API 协议、Base URL、模型列表、默认模型和当前 Provider。
- **新增 API Key 本地加密保存**：使用独立主密钥和 AES-GCM 保存 Provider Secret，接口只返回是否已配置。
- **新增历史会话列表和恢复**：按工作区列出历史对话、读取用户/助手消息并继续已有 Session。
- **演进 Skill 合并规则**：全局与工作区 Skill 同时发现，同名时工作区完整覆盖全局版本。
- **新增 Skill 安装目标**：`install_skill` 默认安装到全局，也可通过 `target=workspace` 安装到当前工作区。
- **演进 WebUI 设计变量**：统一字体、圆角和组件尺度。

### 2026-08-24 — 无 Key 启动、模型同步与会话删除

- **新增无 API Key 启动 Server**：允许先启动 WebUI，再通过 Provider 设置完成配置。
- **演进模型切换一致性**：页面 Provider/模型切换同步到当前 Session，并在切换请求完成前阻止并发提问。
- **新增删除历史会话**：WebUI 可以删除当前工作区内的 Chat Session，并通过 Session Store 安全移除数据。
- **演进默认 Agent Prompt**：加强完成闭环、验证、交付说明和行为边界。

### 2026-08-25 — 模型请求韧性与工具时间线折叠

- **新增模型请求自动重试**：三种内置协议对 429、5xx、可恢复网络错误和结构化流内限流/过载错误自动重试一次。
- **新增 `Retry-After` 支持**：429/503 尊重服务端建议，等待时间上限为 10 秒。
- **新增推理参数能力降级**：上游明确拒绝 reasoning 参数时，移除该参数重试，并按协议、端点和模型缓存能力限制。
- **增强流式请求安全**：收到任何文本、推理或工具增量后不再重放请求，避免重复生成副作用。
- **新增多轮工具调用折叠**：WebUI 将连续工具活动聚合显示，降低长任务时间线噪音，同时保留展开查看能力。
- **同步默认工具说明**：内置 `TOOLS.md` 与当前工具定义、参数和安全边界保持一致。
- **演进设置入口布局**：避免设置按钮被页面底部遮挡。

## 当前演进主线总结

从提交历史看，bqAgent 的演进可以归纳为五条连续主线：

1. **执行内核**：最小工具循环 → 规划、多轮、流式 → 自动上下文压缩 → 截断 Fail-Closed 与模型请求韧性。
2. **工作区与知识**：Markdown 上下文 → Skill/Memory → 渐进式 Skill → 全局与工作区分层配置。
3. **交互渠道**：CLI → HTTP/ServerChan → 微信 iLink/QQ → 内嵌 WebUI 与多工作区桌面体验。
4. **扩展能力**：基础文件/Shell → 搜索抓取 → Claude Code 风格工具与并行执行 → MCP、外部 Agent 和隔离子 Agent。
5. **可恢复与可治理**：Session/日志 → checkpoint/紧凑存储 → Trace/Eval/反馈 → 安全路径、原子写入、超时、停止和重试。
